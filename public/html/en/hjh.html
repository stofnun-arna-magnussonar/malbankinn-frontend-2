The texts by Helgi J. Halldórsson were originally broadcast on the radio programs Daglegt mál and Íslenskt mál from 1973 to 1986.

The radio programs

Þættir Helga J. Halldórssonar um Daglegt mál voru fluttir í fjórum lotum:

  • First round
    • 26.04.1973–26.09.1974
    • 142 programs
  • Second round
    • 02.06.1975–21.11.1975
    • 50 programs
  • Third round
    • 11.06.1976–28.07.1977
    • 113 programs
  • Fourth round
    • 04.05.1981–14.01.1982
    • 72 programs

In total, there were 377 programs broadcast, each containing over 700 words.

Additionally, Helgi presented 24 programs with the title Íslenskt mál from 04.09.1985 to 26.02.1986. (Sigrún Helgadóttir wrote and read three of these programs.)

Thus, the total number of programs is 401.

The texts

The original manuscripts were typed on a manual typewriter and stored in folders. In the spring of 2020, Sigrún Helgadóttir digitized the manuscripts using equipment at the Árni Magnússon Institute. The process involved: Scanning the original pages using a specialized scanner Optical Character Recognition (OCR) to extract text Conversion into digital text using ABBYY FineReader For each episode, a PDF file containing an image of the original text and a corresponding digitally processed text document were created. Guðný Helgadóttir received the text documents, which were processed using the spelling checker Skrambi (http://skrambi.arnastofnun.is/), developed by Jón Friðrik Daðason. The documents were then corrected with the help of Skrambi and compared to the original text. Guðný Helgadóttir carried out this work during the summer and autumn of 2020.

Type style

Since Helgi used a typewriter, the only form of type style he employed was underlining. However, no consistent pattern was observed in its use. While underlining was likely intended for emphasis, it does not necessarily indicate a focus on specific words. For this reason, underlining has not been included in the modified text files.

Corrections

Helgi’s original documents contain handwritten corrections, which were followed during the correction process. The scanning system sometimes had difficulty processing heavily annotated pages, so some content had to be manually keyed.

Spelling

Helgi adhered to the official spelling conventions of his time and did not use the letter ‘z’, which was no longer in standard usage when the programs were broadcast. However, some parts of the texts discuss this letter. Any obvious spelling or typographical errors were corrected.

Processing of the texts

The texsts where tokenized using using Tokenizer from Miðeind (https://github.com/mideind/Tokenizer) POS Tagging was done with the grammatical tagger ABLTagger (http://hdl.handle.net/20.500.12537/98) and the lemmatization was conducted using Nefnir (https://github.com/jonfd/Nefnir)
